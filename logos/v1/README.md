# Stochastic Labs — Logo

The Stochastic Labs mark is a rounded die whose pips are joined by a random walk: dice for gaming, a random process for "stochastic".

## Files

| File | Use |
|---|---|
| `lockup-color.svg` | Primary horizontal logo on light backgrounds |
| `lockup-reversed.svg` | Horizontal logo on dark backgrounds (dark shirts, card fronts) |
| `lockup-one-color.svg` | Single-ink printing, embroidery |
| `mark-color.svg` | Mark only, light backgrounds |
| `mark-reversed.svg` | Mark only, dark backgrounds |
| `mark-one-color.svg` / `mark-one-color-white.svg` | Single-ink mark, black or white |
| `app-icon.svg` | Square icon, avatars, favicons |

## Colors

| Name | Hex |
|---|---|
| Ink | `#111111` |
| Paper | `#F4F1EA` |
| Signal (accent) | `#FF4F1F` |

## Type

- **Space Grotesk Bold** — "Stochastic"
- **JetBrains Mono Bold**, wide tracking — "LABS"

Both are free on Google Fonts.

## Printing notes

- The lockup SVGs use live text. Install both fonts, or convert the text to outlines (Inkscape: Path → Object to Path; Illustrator: Type → Create Outlines) before sending files to a printer.
- For screen-printed shirts, use the one-color or reversed versions; the mark has no gradients or fine detail.
- Keep clear space around the logo of at least half the mark's width. Below about 32px, use the mark alone.

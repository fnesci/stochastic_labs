# Stochastic Labs — Logo v2

The mark is a stylized chart: a normal (Gaussian) curve with **mean 10.5** and **standard deviation 2.96** over a histogram of whole-number outcomes, with a dashed line at the mean. Those are the mean and standard deviation of rolling three six-sided dice (3d6).

## Files

| File | Use |
|---|---|
| `lockup-color.svg` | Primary horizontal logo on light backgrounds |
| `lockup-reversed.svg` | Horizontal logo on dark backgrounds (dark shirts, card fronts) |
| `lockup-one-color.svg` | Single-ink printing, embroidery |
| `mark-color.svg` | Full mark (curve + histogram), light backgrounds |
| `mark-reversed.svg` | Full mark, dark backgrounds |
| `mark-one-color.svg` / `mark-one-color-white.svg` | Single-ink full mark, black or white |
| `mark-small.svg` | Simplified curve-only mark for small sizes |
| `mark-small-one-color.svg` | Simplified mark, single ink (left-chest prints) |
| `app-icon.svg` | Square icon, avatars, favicons |

Both are free on Google Fonts.

## Usage notes

- Below about 64px the histogram bars blur together; use `mark-small.svg` or `app-icon.svg` instead.
- The lockup SVGs use live text. Install both fonts, or convert the text to outlines (Inkscape: Path → Object to Path; Illustrator: Type → Create Outlines) before sending files to a printer.
- For screen-printed shirts, use the one-color or reversed versions.
- Keep clear space around the logo of at least half the mark's height.
